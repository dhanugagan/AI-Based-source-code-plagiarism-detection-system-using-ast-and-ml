# Frontend — CodeGuard Web App

React + Vite + Tailwind CSS client for the CodeGuard plagiarism detection API.
See the [project root README](../README.md) for full setup instructions.

## Run

```bash
npm install
cp .env.example .env
npm run dev
```

Set `VITE_API_BASE_URL` in `.env` if the backend isn't on `http://localhost:8000`.
